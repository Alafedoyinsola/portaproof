# PortaProof

PortaProof is a hackathon milestone tracker prototype designed to help builders record project progress and prepare for verifiable milestones on Portaldot.

## Current Features

- Create project milestones.
- Track milestone status: Planned, In progress, or Completed.
- Delete milestones.
- View total milestones, completed milestones, and completion percentage.
- Save milestone data in the browser using local storage.

## Technology Stack

- React
- TypeScript
- Vite
- CSS

## Current Status

The dashboard prototype is working. Portaldot V3 testnet integration and on-chain milestone verification are planned but have not yet been implemented.

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Network

The intended target is the Portaldot V3 testnet. On-chain functionality is still under development.
